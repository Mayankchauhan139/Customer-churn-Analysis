# 📊 Customer Churn Analysis Using Python and Power BI

## 📌 Project Overview

Customer retention is a major challenge for businesses, especially in subscription-based industries. Losing existing customers, commonly known as **customer churn**, can significantly impact revenue and long-term business growth.

This project analyzes customer data to identify the key factors associated with customer churn. Using Python-based data analysis and visualization techniques, the project explores customer demographics, account information, service usage, contract types, payment methods, and billing patterns to uncover customer segments that are more likely to leave.

The goal of this analysis is to transform raw customer data into meaningful business insights that can help organizations improve customer retention and reduce churn.

---

## 🎯 Business Problem

A company is experiencing customer churn and wants to understand:

* Which types of customers are most likely to churn?
* Are contract types associated with customer churn?
* Does customer tenure influence churn behavior?
* Which payment methods are associated with higher churn?
* Do monthly charges affect the likelihood of customers leaving?
* Which customer segments should the business prioritize for retention efforts?

This analysis aims to answer these questions through exploratory data analysis and data visualization.

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Understand the structure and characteristics of the customer dataset.
2. Clean and prepare the data for analysis.
3. Explore customer demographics and service-related attributes.
4. Analyze customer churn across different customer segments.
5. Identify key factors associated with higher churn rates.
6. Visualize patterns and trends using Python.
7. Generate actionable business recommendations to improve customer retention.
